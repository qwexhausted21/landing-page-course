# 🎓 AI School - Landing Page

Современный, адаптивный лендинг для онлайн-школы, обучающей Python и нейросетям. Создан с упором на высокую скорость загрузки, чистый код и отличный пользовательский опыт (UX).

## 🔥 Особенности проекта

*   **Полностью адаптивный дизайн:** Идеально отображается на ПК, планшетах и смартфонах (включая кастомное меню-бургер).
*   **Интерактивный аккордеон:** Плавное раскрытие модулей программы курса без использования сторонних библиотек.
*   **Анимации при скролле:** Элементы плавно появляются при прокрутке страницы (реализовано через нативный `IntersectionObserver`).
*   **Валидация формы:** Имитация отправки данных с блокировкой кнопки и уведомлением об успехе.
*   **Современная верстка:** Использование Flexbox и CSS Grid, CSS-переменных для легкой смены цветовой темы.

## 🛠 Технологии

*   **HTML5** (Семантическая верстка, OpenGraph теги)
*   **CSS3** (Flexbox, Grid, CSS-переменные, медиа-запросы, анимации)
*   **JavaScript (ES6+)** (Работа с DOM, обработка событий, IntersectionObserver)
*   **Google Fonts** (Шрифт Inter)

## 🚀 Как запустить

Проект не требует сборки или установки зависимостей. 
1. Скачайте файлы.
2. Откройте `index.html` в любом современном браузере.
